# 轻记账 · 智能记账 (Smart Record)

本地优先的 Android 个人记账应用。界面设计对齐一木记账交互规范，支持智能自动分类、日 / 周 / 月 / 年全周期统计分析，以及对齐一木记账 23 列标准格式的 Excel 账单导入导出。数据保存在本机，**不申请任何网络权限**。

## 核心特性

### 1. 记账与智能速记
- **基础记账**：支出 / 收入方向切换、分类网格、商户 / 交易对象、备注、日期与时间选择。
- **智能速记**：在记一笔页面输入任意自然语句（例如「妈妈微信转账生活费2000」或「麦当劳汉堡38.5」），自动解析金额、匹配对应分类并联动方向。
- **一键固化为规则**：在记一笔或编辑时，支持勾选「记住为自动分类规则」，后续包含该关键词的账单将自动归入对应分类。
- **日期跟随**：主页概览自动跟随设备系统日期，支持跨月切换与快速返回当月。

### 2. 五级规则链与分类引擎
分类引擎具备清晰的优先级链路，命中即返回：
1. **商户记忆**：针对用户手动修改过分类的商户，下次记录时自动沿用历史选择。
2. **自定义规则**：用户在规则界面维护的关键词与分类映射，优先级高于系统默认值。
3. **平台自带分类**：解析微信「交易类型」与支付宝「交易分类」权威字段。
4. **内置规则**：内置丰富的高频生活关键词体系（深度覆盖餐饮、居住、交通、教育、兼职、生活费、奖学金等场景）。
5. **兜底分类**：未命中任何规则时，按收支方向分别归入「其他」或「其他收入」。

### 3. 规则管理与演练场
- **规则测试演练**：在规则管理页面提供演练输入框与收支方向切换，即时呈现匹配分类、命中层级与依据关键词。
- **常用预设推荐**：提供校园与日常生活高频词（生活费、妈妈转账、奖学金、监考费、晚饭、洗衣服、空调费、水卡、电卡等）快捷一键添加。
- **规则检索与多维筛选**：支持按「全部 / 自定义 / 内置」分类浏览，支持输入关键词动态搜索。
- **商户记忆管理**：支持查看当前已积累的商户记忆数量，并提供一键清空功能。

### 4. 统计与支出占比分析
- **多维度周期统计**：支持「本周 / 本月 / 本年 / 自定义区间」四种周期，支持年到月、月到周逐级下钻分析。
- **图表展示**：提供收支趋势柱状图与支出占比环形图，展示环比上期、日均支出与分类排行榜。
- **全屏交互**：支持周期快速切换与子周期过滤高亮，直观分析资金流向与消费构成。

### 5. 一木记账标准 23 列 Excel 备份与导入导出
- **导出规格**：严格遵循一木记账标准 23 列表头结构，首表输出完整交易流水（记账时间、类型、金额、一级分类、二级分类、账户、账本、标签、备注等），支出金额记录为负数，第 18 列（其他）保存校验哈希与商户信息。第二表输出各分类收支与结余统计汇总。
- **双格式解析**：支持一木记账导出的 `.xls`（BIFF8 格式）与现代 `.xlsx` 格式文件的导入与解析。
- **无损导入与去重**：导入时智能解析一木记账二级分类映射，依据交易哈希自动完成重复校验与去重，保护数据一致性。
- **第三方账单导入**：支持微信支付账单（.xlsx）与支付宝交易明细（.csv）解析导入。

### 6. 自动记账（无障碍与通知监听）
- 依据无障碍服务与通知使用权监听支付通知，弹出半自动悬浮确认卡片，经由用户确认后记录入账。
- 零网络权限，解析逻辑全部在 Android 本机运行。

## 使用的技术

| 项目 | 说明 |
| --- | --- |
| 开发语言 | Kotlin 2.2 |
| UI 框架 | Jetpack Compose (Material 3，对齐现代设计规范) |
| 本地存储 | Room Database + DataStore Preferences |
| Excel 解析与构建 | 自研 MiniXlsx（标准 OpenXML） + JExcelApi（BIFF8 引擎） |
| 应用架构 | MVVM，Coroutines，StateFlow / SharedFlow，Navigation Compose |
| 构建系统 | Android Gradle Plugin 9.0，Gradle 9.5，KSP |

最低支持版本：Android 8.0（API 26）。

## 构建与运行

1. 配置 JDK 21 环境与 Android SDK。
2. 克隆仓库到本地：
```bash
git clone https://github.com/73mtq/smart-record.git
cd smart-record
```
3. 运行构建命令：
```bash
./gradlew assembleDebug
```
4. 构建产物位于 `app/build/outputs/apk/debug/app-debug.apk`。
