# 智能记账系统（基于轻记账底座与一木记账界面规范）实现报告

## 1. 架构总览与选型

本项目以开源项目 `Lite_Bookkeeping`（Apache-2.0 协议）作为底层基础，融合一木记账的视觉与交互设计，实现了一款纯本地运行、零多余权限的个人记账 Android 应用程序。

### 核心采用的技术方案
- **编程语言**：Kotlin 2.2
- **界面体系**：Jetpack Compose（Material 3 体系，采用一木记账温润卡片与治愈色系进行深度定制）
- **数据持久化**：Android Jetpack Room + SQLite
- **报表与导出**：自研轻量级 `MiniXlsx`，纯原生生成支持多工作表的 `.xlsx` 格式文件
- **权限安全**：完全不声明 `android.permission.INTERNET` 网络权限，全部数据保存在设备本地

## 2. 关键需求实现与优化

### 2.1 输入信息自动选择分类（五级优先链实时联动）
在记账表单 ViewModel（`AddEditViewModel`）与界面（`AddEditScreen`）中建立实时智能分类识别机制：
1. **五级权威匹配链**：
   - 第一级：商户记忆（用户在历史记录中人工修正过的商户对应关系）
   - 第二级：自定义关键词规则（用户显式配置的映射关系）
   - 第三级：平台自带分类（微信与支付宝权威分类）
   - 第四级：内置关键词规则库（涵盖 500 余条日常消费与收入关键词）
   - 第五级：兜底默认分类
2. **表单输入实时感知**：用户在输入“商户”或“备注”时，系统就地调用规则引擎快照进行分类推断，并在分类九宫格中实时选中推荐项，同时呈现“✨ 智能匹配: [分类名称]”提示徽章。
3. **自然文本速记解析**：在表单顶部提供智能速记输入栏，支持用户粘贴或输入复合短语（例如“妈妈转账生活费2000”或“麦当劳汉堡38.5”），自动提取金额并联动选择对应分类与收支方向。

### 2.2 妈妈转账、生活费与奖学金分类及口径建模优化
针对生活费、奖学金与普通劳动收入混同导致的月收入虚高与支出占比分母失真问题，重构分类与财务模型：
1. **第一梯队分类新增**：在 `Categories.kt` 中正式引入“生活费”（对应图标 🏡）与“奖学金”（对应图标 🎓）。
2. **规则词库增补**：
   - 生活费规则：“生活费转账”、“妈妈转账”、“爸爸转账”、“家里转账”、“生活费”、“生活补助”、“家庭补贴”、“家庭支持”、“生活金”、“妈妈”、“爸爸”。
   - 奖学金规则：“国家奖学金”、“励志奖学金”、“学业奖学金”、“单项奖学金”、“校奖学金”、“奖学金”、“助学金”、“竞赛奖励”。
3. **收入性质分组（`IncomeGroup`）**：
   - 家庭支持类（SUPPORT）：“生活费”
   - 奖助资助类（MERIT）：“奖学金”
   - 劳动报酬类（EARNED）：“工资”、“兼职”
   - 往来理财类（CAPITAL_AND_OTHER）：“红包”、“退款”、“理财”、“其他收入”
   在统计页面分类排行榜中，为该类项目直接打上对应性质标签，清晰呈现“钱从哪来”。

### 2.3 多维度统计报表与占比环形图
1. **时间周期支持**：支持“本周”、“本月”、“本年”、“自定义区间”四类周期。
2. **下钻与趋势**：本年视图支持下钻到 12 个月度，本月视图支持下钻至各个自然周，支持日均值与环比上期波动浮动计算。
3. **支出占比与收入构成双重视图**：
   - 支出方向：通过 DonutSection 环形图呈现全部支出分类的占比比例，并在下方排行榜呈现笔数与百分比进度条。
   - 收入方向：切换至“收入”时，标题自动转换为“收入来源构成（钱从哪来）”，直观展示生活费、奖学金与工资的贡献比率。

### 2.4 人类与 AI 友好的多工作表 Excel 导出与导入
升级 `MiniXlsx` 与 `BackupExporter`，导出文件包含双工作表：
1. **工作表 1：`账单明细`**
   - 字段序列：`记账时间`、`类型`、`金额`、`分类`、`商户/交易对象`、`备注`、`来源`、`校验码`。
   - 严格兼容应用内置的 `BackupExcelParser`，可由用户修改后重新无损导入，按 SHA-256 校验码精准去重。
2. **工作表 2：`统计汇总`**
   - 包含全局财务指标（账单总笔数、累计总支出、累计总收入、累计净结余）。
   - 包含按金额降序排列的“支出分类占比排行榜”与“收入来源构成排行榜”。
   - 附带 AI 分析提示说明，方便直接上传至大语言模型进行个人消费诊断。

### 2.5 一木记账视觉规范实践
- **主色调**：采用一木生机森绿（`#24B064`），暗色模式适配柔光翡翠绿（`#2DC574`）。
- **收支对比色**：支出采用明媚暖珊瑚红（`#FF5A5F`），收入采用生机翠绿（`#24B064`）。
- **卡片质感**：采用温和纸底浅灰（`#F7F9F8`）与纯白卡片（`#FFFFFF`），配合 18dp 至 24dp 优雅圆角。
